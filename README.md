📞 Call Center Analytics Dashboard

Python + Excel + Power BI

A data analytics project that transforms raw call center data into actionable insights using Python for data processing, Excel for structured storage, and Power BI for interactive visualization.

The dashboard provides performance monitoring across call volume, duration, sentiment, channels, and locations to support operational decision-making.

🚀 Project Overview

This project demonstrates an end-to-end analytics workflow:

✅ Data collection and preprocessing with Python

✅ Data storage and validation in Excel

✅ Interactive dashboard creation in Power BI

The result is a business-ready dashboard for monitoring customer service performance.


📊 Dashboard Features

The Power BI dashboard includes:

★ Total Calls Overview

  Total calls handled

  Total call duration (minutes & hours)

  Average call duration

  Response time percentage

★ Call Volume Analysis

   Calls by day of week

   Calls by geographic location

   Calls by call center

★ Customer Interaction Insights

   Calls by communication channel (Call Center, Chatbot, Email, Web)

   Calls by reason (Billing, Service, Payments, etc.)

   Calls by sentiment (Negative → Very Positive)

★ Interactive Filters

   Date range selection
   
   Channel filter

   City filter
